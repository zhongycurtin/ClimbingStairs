# 步步登峰 (StairStep) - 爬楼梯减脂 Android 原生应用

专为“爬楼梯减肥/自律健身”打造的极简主义设计感 Android 原生应用。基于 **Kotlin + Jetpack Compose + Material 3** 构建，兼顾白日摸鱼微运动与晚间集中燃脂，配合科学体重卡路里模型与双曲线成就看板。

---

## ✨ 核心特性

1. **核心大按钮打卡与自适应计时**
   - **实时计时模式**：点击“开始爬楼”，秒表运转；爬到顶层后点击“完成（+1）”，自动结算本次耗时与起止时间。
   - **摸鱼快捷+1**：白天摸鱼爬没带手机或未开计时，支持一键快捷+1，智能计算均速与当前时间。
   - **单趟流水时间轴**：记录每一趟的具体开始时间（如 `10:25 白天摸鱼`、`20:15 晚间燃脂`）与用时明细。

2. **自定义楼层与科学卡路里**
   - **自定义单趟楼层**：支持随时设置家住6楼或公司18楼等，实时换算累计总楼层与垂直提升高度（米）。
   - **体重联动算法**：输入体重后，依据爬楼代谢模型（MET 8.8）精准计算每一趟的卡路里燃烧。

3. **漏记历史补录**
   - 某一天忘记打开手机记录？提供专用“补录”功能，仅需输入日期、爬升楼层数与当日体重，即可自动补齐运动历史。

4. **双曲线统计与成就感体系**
   - **每日运动量曲线**：柱状趋势图展示近 7 天 / 30 天每日爬升层数与趟数。
   - **体重变化折线图**：平滑贝塞尔曲线直观展现减脂成效。
   - **地标攀登里程碑**：累计爬升高度自动对比埃菲尔铁塔、东方明珠、台北101、广州塔小蛮腰、泰山等。

5. **数据导出与备份**
   - 支持一键导出所有记录为标准 **CSV 格式**（包含爬楼流水表与体重历史表），方便在 Excel 或 Notion 中查看。

---

## 🛠️ 技术架构

- **语言**：Kotlin 2.0+
- **UI 框架**：Jetpack Compose + Material 3
- **架构设计**：MVVM + StateFlow + Kotlin Coroutines
- **本地持久化**：
  - **Room Database** (`ClimbTrip`, `WeightRecord`)
  - **Jetpack DataStore Preferences** (存储单趟楼层数、默认体重)
- **图表展示**：Compose Canvas 原生平滑贝塞尔曲线与柱状图（无需笨重外部图表库）
- **数据导出**：Android FileProvider + Intent Sharesheet

## 🚀 运行方式

### 方式一：在 Android Studio 中打开与编译运行
1. 打开 **Android Studio** (推荐 Iguana / Ladybug 或更高版本)。
2. 点击 **Open**，选择本项目根目录：`h:\Projects\ClimbingStairs`。
3. 等待 Gradle 同步完成后，连接 Android 真机或启动模拟器，点击 **Run 'app'** 即可直接安装运行。

### 方式二：即时在浏览器中试玩（无需配置 Android SDK）
本项目贴心配套了 1:1 还原的 Web 交互预览版：
- 直接双击打开 `web_preview/index.html`。
- 或在项目根目录下运行命令行：
  ```bash
  & "C:\Program Files\nodejs\node.exe" serve.js
  ```
  然后在浏览器中访问 `http://localhost:3000` 即可在手机画框中完整试玩所有功能与下载 CSV！
